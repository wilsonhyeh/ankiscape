# Fish / cooked icons - attribution

All 18 files under `fish/` are deterministic 1x1 PNG placeholders generated by
`evolved/icons.py` (no runtime downloads). They ship so every Fishing/Cooking
resource resolves an icon path on all platforms.

To replace with real art: drop `<fish>.png` / `cooked_<fish>.png` files here
(lowercase IDs: shrimp, sardine, trout, tuna, lobster, swordfish, monkfish,
shark, anglerfish) and record the source + license in this file. Keep the
existing filenames stable; rules reference fish IDs, not pixels.
