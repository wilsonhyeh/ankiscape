# Support

AnkiScape is an independent, noncommercial passion project made out of love
for Old School RuneScape. It is not affiliated with or endorsed by Jagex Ltd.

## Reporting a bug

Use the in-game **Report a bug…** entry (Settings → Advanced, the Guide, or the
game-recovery banner). It builds a prefilled GitHub issue you review before
opening; nothing is uploaded automatically. You can also open the
[Bug report](https://github.com/wilsonhyeh/ankiscape/issues/new?template=bug_report.yml)
form directly.

Include:

- Anki and AnkiScape versions and your OS;
- numbered steps, expected behavior and actual behavior;
- how reproducible it is;
- optional **allowlisted diagnostics** (the dialog's preview is exactly what
  gets copied). Never paste raw logs.

## Never post publicly

- collections, decks, cards or notes;
- emails, usernames, account, game or device ids;
- tokens, passwords, cookies, API keys;
- full file paths, hostnames, IPs or backend responses.

## Security issues

Do **not** open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md) instead.

## Questions

Search existing issues first. Feature ideas are welcome through the Feature
request form.
